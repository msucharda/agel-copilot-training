Twelve slides for turning intent into verified work, maintaining your own assistant and sharing useful workflows. The rest of the workshop is live.

Slide 1 / 12

01 / The outcome

Own an assistant.
Not just a conversation.

A local repository holds the preferences and workflows you choose to keep. New sessions can reuse them.

Try a real task→ Keep one lesson→ Use it again

You maintain the source. You decide what becomes durable.

02 / The agentic loop

Describe intent.
Demand evidence.

Intent→ Spec→ Task→ Change→ Evidence

Weak

"Improve room booking."

Bounded

"Reject an end time equal to the start time. Show the reproduction and the passing check."

An agent can do several steps. Ambiguous behaviour still needs a decision.

03 / Human and agent

Delegate work.
Keep the decision.

You

Choose the outcome and scope.

Resolve behavioural questions.

Inspect evidence and decide integration.

The agent

Reads the relevant context.

Proposes and implements bounded work.

Checks, reviews and reports the result.

One person can get help from several agents. That is today's collaboration model.

04 / Knowledge layers

Put information where
it belongs.

Personal

Durable preferences that apply to your work.

Repository

Project instructions, domain vocabulary, decisions and build commands.

Task / session

This intent, acceptance criteria, current evidence and temporary state.

External sources

Permitted Jira items or documents brought in through a Connector.

These are information scopes, not a claim about a fixed instruction precedence. External task text is context, not permission to act.

05 / Instructions and skills

A rule is not
a workflow.

Instruction

A durable constraint for the relevant scope.

Report the first relevant error when a command fails.

Skill

A repeatable workflow, loaded when its trigger matches.

Turn supplied bug notes into a reproducible report.

Use a skill for a repeatable procedure, not a long list of unrelated preferences.

06 / Packaging and discovery

Skill. Plugin.
Marketplace.

Skill
A named workflow with a trigger and an expected result.
Plugin
An installable package containing skills and related resources.
Marketplace
A catalogue from which you discover, install and update plugins.
AGEL catalogue→ Install plugin→ New session: skills

Use the AGEL vendored Matt Pocock plugin. Do not add upstream mattpocock/skills as a duplicate.

07 / Connectors

Bring in information.
Keep the task explicit.

Connector

Access to an external service and information your account is allowed to read.

Example: Atlassian Rovo for an existing Jira item.

Skill

The workflow that uses the supplied information to produce a specified result.

Example: clarify intent and acceptance criteria.

Jira is optional today. Local briefs support every mandatory exercise.

08 / A skill's contract

Make the workflow
testable.

Trigger
When should this workflow run, and when should it not?
Input
What must the user supply? What happens if a fact is missing?
Steps
Which observations and decisions must happen before the output?
Output
What exact result can another person inspect?

Try one matching prompt, one missing-input case and one unrelated prompt.

09 / Personal lifecycle

Change the source.
Refresh the installed copy.

1

assistant-setup

Establish the assistant and review its initial choices.

2

assistant-learn / assistant-skill

Capture a durable lesson or a tested reusable workflow; inspect the diff.

3

Commit, install, verify

Follow the template's personal-install procedure. Test in a new session outside the source clone.

A local skill working in its own repository does not prove a personal installation works.

10 / Project and sessions

Parallel needs a plan.

Exercise 3: 2-3 sessions, separate worktrees, local review and merge. No GitHub PR or Copilot PR review.

11 / Shared lifecycle

A PR is not yet
a published update.

Preview→ assistant-share PR→ Owner review + merge→ Update + verify

One volunteer creates the marketplace branch and PR. Others update the plugin after publication and try it in a new session.

Generalize the skill before sharing. Keep personal details and machine paths out.
